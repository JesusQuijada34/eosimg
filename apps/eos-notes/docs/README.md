# EOS Notes

Utilidad local de notas para EOS, escrita en EosLang 0.1. El proyecto demuestra la estructura que después será compilada por `eoslangc`, empaquetada por la herramienta oficial y firmada como `.eapp`.

La aplicación no solicita permisos de red, cámara, micrófono ni almacenamiento externo. Su persistencia real queda pendiente de la API de documentos EOS; esta primera versión solo valida el entrypoint EOSBC y la identidad del paquete.

Este directorio contiene únicamente fuentes y metadatos de desarrollo. No se publica el `.eapp` generado ni una imagen de EOS.
